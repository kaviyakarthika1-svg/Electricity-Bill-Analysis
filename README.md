# Electricity Bill Analysis

A Python-based data analysis and visualization project for analyzing electricity consumption and bill amounts.

## Technologies Used

- Python
- Pandas
- Matplotlib
- Seaborn

## Dataset

The project uses `Electricity_bill.csv`, which contains electricity consumption and customer information.

## Analysis Performed

- Display first 5 rows
- Check dataset shape and columns
- Display dataset information
- Generate statistical description
- Check missing values
- Calculate electricity bill
- Find average bill
- Find highest bill
- Find lowest bill

## Visualizations

- Bill Amount Distribution
- Units Consumed vs Bill
- Average Bill by City
- Bill Amount Box Plot
- Correlation Heatmap
